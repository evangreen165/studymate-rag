# Документация проекта

| Раздел | Что внутри |
| --- | --- |
| [Пояснительная записка](pz/README.md) | ПЗ на 49 страниц по СТП 01-2024: исходники Markdown, сборщик, DOCX и PDF |
| [Графическая часть](graphics/README.md) | Четыре листа А4 по ГОСТ 19.701-90: архитектура, пайплайн, варианты использования, результаты |
| [Презентация](presentation/README.md) | 15 слайдов для защиты, PPTX и PDF |
| [GitHub Pages](site/index.html) | Лендинг проекта с метриками и скриншотами |
| [Изображения](images) | Схемы, графики EDA, скриншоты интерфейса |

Пояснительная записка собирается из `pz/content/*.md` скриптом `pz/build_pz.py`. Числа корпуса и метрик подставляются из `data/manifest.json`, `data/index_meta.json` и `results/ragas_test.json`.

Графические листы и презентация используют изображения из `images/` и метрики из `results/`, поэтому после пересчёта оценки достаточно пересобрать документы командами из README соответствующих папок.
