# Графическая часть

Четыре листа А4 по ГОСТ 19.701-90:

1. `Лист_1_Архитектура.pdf` — схема архитектуры (UML deployment).
2. `Лист_2_Пайплайн.pdf` — диаграмма данных и пайплайна.
3. `Лист_3_Варианты_использования.pdf` — UML use case.
4. `Лист_4_Результаты_оценки.pdf` — метрики RAGAS и сравнение с baseline.

Сборка:

```bash
uv run python docs/graphics/build_graphics.py
```

Скрипт использует изображения из `docs/images/` и формирует PDF с рамкой и основной надписью
`ГУИР 381571.14.001`–`.004`. Для печати достаточно открыть PDF и выбрать «Фактический размер».
