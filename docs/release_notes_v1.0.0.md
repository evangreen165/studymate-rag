## StudyMate v1.0.0 — курсовая версия

RAG-ассистент по учебным материалам курса: отвечает на вопросы студентов по PDF-конспектам, показывает источники со страницами и проходит количественную оценку качества.

### Что входит

- Гибридный поиск: ChromaDB (USER2-base, 794 стратифицированных чанка) + BM25 по 18 693 чанкам, объединение RRF и MMR.
- Генерация: Llama-3.1-70B через OpenRouter, локальный Qwen2.5-7B как резерв, экстрактивный fallback.
- FastAPI, Streamlit с управлением корпусом и историей чатов, Docker Compose, GitHub Actions.
- Пояснительная записка (49 страниц), 4 листа А4 по ГОСТ 19.701, презентация на 15 слайдов.

### Полный корпус

41 авторский PDF и GGUF-модель в репозиторий не входят. Для воспроизведения используется демонстрационный корпус из 7 синтетических конспектов (CC BY 4.0); порядок сборки полного корпуса описан в `data/README.md`.
