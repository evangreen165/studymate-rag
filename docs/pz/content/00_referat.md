# РЕФЕРАТ

Пояснительная записка к курсовой работе содержит 44 страницы, 12 рисунков, 19 таблиц, 20 источников, 2 приложения.

**Тема:** «Ассистент по учебным материалам курса с ответами на вопросы студентов».

**Объект исследования** — процесс поиска ответов на вопросы студентов по учебным материалам курса.

**Предмет исследования** — методы и архитектурные решения retrieval-augmented generation (RAG), гибридного поиска и оценки качества генеративных ответов.

**Цель работы** — разработать прототип прикладной интеллектуальной системы, которая отвечает на вопросы студентов по корпусу учебных PDF-материалов, опирается только на найденные фрагменты, показывает источники и проходит количественную оценку качества.

**Методы:** анализ предметной области, проектирование архитектуры, извлечение и очистка PDF, чанкинг, плотные эмбеддинги USER2-base, векторный поиск в ChromaDB, разреженный поиск BM25, объединение результатов через Reciprocal Rank Fusion, генерация ответа большой языковой моделью Llama-3.1-70B через OpenRouter, оценка качества с помощью RAGAS, сравнительный анализ с baseline без поиска.

**Полученные результаты.** Сформирован корпус из {{DOCS}} PDF-документов объёмом {{PAGES}} страниц ({{TEXT_PAGES}} страниц с текстовым слоем). Построен гибридный индекс: {{BM25_CHUNKS}} чанков для BM25 и {{DENSE_CHUNKS}} стратифицированных чанков для плотного индекса ChromaDB. Реализованы REST API на FastAPI, веб-интерфейс на Streamlit с управлением корпусом и историей чатов, контейнеризация Docker, CI на GitHub Actions. На отложенной тестовой выборке из 30 вопросов получены значения Faithfulness {{FAITH}}, Answer Relevancy {{REL}}, Context Precision {{PREC}}, Context Recall {{REC}}; baseline без поиска — Answer Relevancy {{BASE_REL}}, Answer Correctness {{BASE_CORR}}. Целевые значения по Faithfulness (≥ 0,80) и Answer Relevancy (≥ 0,75) достигнуты.

**Ключевые слова:** RAG, большие языковые модели, поиск по документам, эмбеддинги, ChromaDB, BM25, LlamaIndex, FastAPI, Streamlit, RAGAS, оценка качества, учебные материалы.
