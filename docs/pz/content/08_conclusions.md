# ВЫВОДЫ

В ходе выполнения курсовой работы получены следующие результаты.

1. **Изучены** предметная область и существующие подходы к поиску ответов по учебным материалам. Обоснован выбор архитектуры retrieval-augmented generation, сформулированы формальная постановка задачи, функциональные и нефункциональные требования.
2. **Собраны и паспортизированы** {{DOCS}} PDF-документов объёмом {{PAGES}} страниц по семи темам. Выполнен разведочный анализ: описаны распределение по темам, сканы, дубликаты, языковые особенности и ограничения данных.
3. **Разработана** архитектура системы, включающая Streamlit UI, FastAPI, RAG-ядро, ChromaDB, BM25-корпус, модель эмбеддингов USER2-base и LLM Llama-3.1-70B; локальная Qwen2.5-7B предусмотрена как офлайн-вариант. Проведён сравнительный анализ моделей и архитектурных подходов.
4. **Реализован** гибридный поиск: плотный индекс на {{DENSE_CHUNKS}} стратифицированных чанках и BM25 на {{BM25_CHUNKS}} чанках, маршрутизация по теме вопроса, фильтрация оглавлений, MMR и взвешенное объединение dense/BM25/coverage/RRF. Построен промпт с цитатами, отказом и защитой от prompt injection.
5. **Реализованы** REST API на FastAPI, веб-интерфейс на Streamlit с управлением корпусом, историей чатов и метриками агента, контейнеризация Docker и CI на GitHub Actions.
6. **Проведена оценка** на отложенной тестовой выборке из 30 вопросов. Получены Faithfulness {{FAITH}}, Answer Relevancy {{REL}}, Context Precision {{PREC}}, Context Recall {{REC}}; baseline без поиска — Answer Relevancy {{BASE_REL}}, Answer Correctness {{BASE_CORR}}. Целевые значения достигнуты.
7. **Выполнен** анализ ошибок: выделены промахи поиска, границы чанков, сканы, многошаговые вопросы, языковой разрыв и избыточность ответа. Определены направления улучшения: OCR, полный плотный индекс, реранкер, перефразирование запроса.
8. **Организована** воспроизводимость: фиксированные версии зависимостей, манифест корпуса с хешами, Docker Compose, тесты и CI. Подготовлены пояснительная записка, графическая часть и презентация.

Практическая значимость работы состоит в том, что прототип можно использовать как основу ассистента по любому учебному курсу: корпус и индекс обновляются без переобучения модели, а ответы содержат проверяемые ссылки на страницы. Архитектура допускает замену модели эмбеддингов, LLM и векторной базы данных.
