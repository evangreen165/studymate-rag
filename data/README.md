# Данные проекта

## Полный корпус

Полный корпус состоит из **41 PDF** по семи темам (Computer Science, Git, Linux, SQL,
алгоритмы и структуры данных, компьютерные сети, ООП). Файлы лежат в тематических
подпапках и **не публикуются в Git**: это авторские учебные пособия, а не открытые
материалы. Манифест, паспорт, хэши и скрипты сборки хранятся в репозитории, сами PDF —
только локально.

Чтобы собрать манифест на своей машине:

```bash
uv run python scripts/build_manifest.py
uv run python scripts/build_index.py
```

## Демонстрационный корпус

`data/demo/` — семь коротких синтетических конспектов (по одному на тему), написанных
специально для проекта. Они распространяются по лицензии CC BY 4.0 и входят в
репозиторий, чтобы `docker compose up --build` работал без полного корпуса.

```bash
uv run python scripts/make_demo_corpus.py
uv run python scripts/build_index.py --demo
```

## Оценка

`data/eval/` содержит валидационный и тестовый наборы вопросов с эталонными ответами и
gold-страницами. Тестовая выборка не используется при подборе параметров.
